## Directory Structure




## Goal:

Goal Drift is an agent's tendency to deviate from its original instruction-specified goal over time. The focus here is to detect goal drift at inference time. We try to keep it agnostic to the cause of the agent's drift, however we will use examples related to the accumulation of interactions in the context window and encountering competing objectives in user interactions.
